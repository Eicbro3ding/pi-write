# 剧本写作方法（stage-scripting）

舞台区共演中，导演通过 `stage_script` 工具输出剧本。本文件是完整方法论；剧本模式下注入的
【剧本写作方法】块是它的精简版。

## 0. 分工原则（最重要）

- 导演写「为什么演」：意图、边界、节拍；**演员写「怎么演」：台词、行为自由发挥**。
- 台词是演员的涌现，不是导演的复述稿。导演写逐句台词 = 演员变复读机，共演就死了。
- 关键事件「**必须发生、措辞自由**」：beats 声明"王五必须挑明那笔债"，不指定怎么说。
- 用户改剧本 = 改意图/边界/节拍，**不替演员写台词**。

## 1. 定义段（definition）

### cast — 选角表

```
"cast": { "actor-1": ["李四"], "actor-2": ["王五"], "actor-4": ["叙述者"] }
```

- 一幕一人一角；同场角色必须由不同演员饰演（杜绝自问自答）。
- 引用编制外演员会自动补为群演槽位（cast.json）。

### inject — 演员知识面（include-only）

```
"inject": { "actor-1": { "characters": ["李四"], "world": ["酒馆"], "budget": 2000 } }
```

- **你决定每个演员知道什么**：characters/world 从 world.json 拉取注入（只取角色/世界条目，
  元信息不外泄）。**没指定的演员不知道**——信息差即悬念（真相节点只给导演，不给演员）。
- 演员的知识面只有你指定这一条来源，没有自动兜底。

### rules — 演出规则

- `minLines` / `maxLines`：对话条数下限/上限（默认 10/20）——收尾判定依据。
- `wrapUpWindow`：收尾窗口（默认 3）——用户示意收尾后，演员在窗口内自然收束。
- `turn`：轮转方式（当前仅 round-robin）。

## 2. 文字段（text）

### shared — 全员可见

| 字段 | 语义 | 禁忌 |
|---|---|---|
| `setting` | 场景意象清单（氛围/关键物件/空间感） | 不是完整描写——呈现交给叙述者 |
| `goal` | 本幕最高任务（这幕要达成什么） | 不要写成剧情梗概 |
| `beats` | 事件序列：**必须发生什么**（每拍一句） | 不是台词稿；措辞留给演员 |
| `tone` | 基调（节奏/情绪/留白） | — |
| `forbidden` | 硬禁区（≤3 条） | 不要堆砌软建议 |

### perActor — 每演员

| 字段 | 语义 | 禁忌 |
|---|---|---|
| `objective` | 角色任务：**角色想要什么**（斯坦尼式） | 不是性格标签——"性格冷淡"无效，"想证明自己还清了债"有效 |
| `state` | 本幕内心状态 | — |
| `relation` | 与在场角色的关系动态 | — |
| `voice` | 说话方式（语速/句式/口头禅） | — |
| `boundary` | 演出边界（每轮上限/潜台词要求） | 每条必须可执行 |
| `examples` | 风格示例 2-3 轮 | **禁止与剧情重复；演员禁止复述；不进舞台转录** |

示例的作用是锁定**说话方式**（模式），不是提供内容（规则）——模型对模式的遵循远超规则。

## 3. 示例剧本（酒馆重逢）

```json
{
  "scene": "第一章·酒馆初遇",
  "chapter": "第一章",
  "cast": { "actor-1": ["李四"], "actor-2": ["王五"], "actor-4": ["叙述者"] },
  "inject": {
    "actor-1": { "characters": ["李四"], "world": ["酒馆"] },
    "actor-2": { "characters": ["王五"], "world": ["酒馆"] },
    "actor-4": { "world": ["酒馆"] }
  },
  "rules": { "minLines": 10, "maxLines": 20, "wrapUpWindow": 3 },
  "text": {
    "shared": {
      "setting": "暮色中的酒馆：烛火、空桌、角落的旧账本（意象清单）",
      "goal": "重逢中揭开三年前的债，或至少埋下伏笔",
      "beats": [
        "拍1·寒暄试探：王五提起三年未见，李四敷衍回避",
        "拍2·冲突点：王五把那本旧账本推过来，李四沉默",
        "拍3·收束：李四说出半句真话，王五不追问"
      ],
      "tone": "克制、压抑，留白",
      "forbidden": ["禁用现代词汇", "不得直接朗读内心想法"]
    },
    "perActor": {
      "actor-1": {
        "objective": "证明自己还清了债、不欠人情——但放不下脸面直说",
        "state": "愧疚又恼怒",
        "relation": "对王五冷淡回避",
        "voice": "短句，口头禅「嗯」",
        "boundary": "每轮不超过两句",
        "examples": ["王五: 三年了，你还活着。", "李四: ……嗯。"]
      },
      "actor-2": {
        "objective": "确认李四过得还行，又不愿显得惦记那笔账",
        "examples": ["王五: 那笔账，我不急。"]
      }
    }
  }
}
```

## 4. 禁忌清单

1. objective 写欲望，不写性格标签。
2. beats 写事件，不写台词稿。
3. examples 禁复述、禁与剧情内容重复；最多 2-3 轮。
4. forbidden 只写硬禁区，别超过 3 条。
5. 角色基础人格在世界书维护（world_update），剧本只写本幕增量——不要每幕重述人物小传。
6. 剧本必须经 `stage_script` 工具输出，禁止以文本形式直接写剧本。
