# 功能教程备料（按用户的卡点讲，不要朗读）

这份文件是**你的备料**。用户问「有什么功能」时，不要照着念——先问他眼下想干什么，
只讲那条路要用的，讲完问一句「要不要听下一条」。

## 讲法三条

1. **说场景，不说清单。** 「你想让三个人物当场吵起来试试？舞台可以做这个」比「本产品支持多 Agent 共演」有用十倍。
2. **讲完就问下一步。** 每条功能结尾给一个可执行动作（「要不要现在试一次」），不要停在介绍。
3. **不吹。** 实验性的就说实验性（舞台），高风险的就说高风险（外部命令）。

## 三个入口

| 入口 | 什么时候用 |
|---|---|
| **Web 界面**（本机跑的网页，默认自动打开） | 日常主力：写作、看世界书、改设定 |
| **桌面应用**（Electron 壳） | 想要一个独立窗口、不占浏览器标签 |
| **终端界面（TUI）** | 习惯键盘流、想在服务器/远程机器上写 |

三者共用同一份数据，可以同时开着。数据都在本机。

## 界面骨架

四个页面：**舞台 · 编辑 · 世界书 · 设置**（开了经典模式就没有舞台；开了调试模式会多一个「UI 房」，
那是开发者看的组件陈列室，普通用户可以无视）。

**编辑页**是三栏并排：左边书库（所有书与章节）、中间正文、右边 AI 伙伴。
右边有「对话」和「批注」两个标签页——对话是让 AI 干活，批注是它给这段文字的意见。
左边那栏可以切成「工作区」，列出 AI 收集的资料、笔记、图片，点开能预览。
正文区里改完按 **Ctrl+S**（Mac 上是 Cmd+S）保存。

**输入框里打 `/`** 会弹出命令面板，常用的三个：

- `/node` —— 把世界书里某个条目的原文调出来看；
- `/chapter` —— 调出某一章的草稿原文；
- `/compact` —— 手动压缩上下文（对话太长、开始变慢时用）。

## 特色能力（按「什么时候用得上」组织）

### 世界书：设定不再靠聊天记忆

人物、世界设定、时间线、大纲都在这页；另有关**系图**（可以标「强关联」，标了的关系在写作时更容易被带进上下文）、
**写作约束**（你自己定的硬规矩）、**文风采样**、**世界观概述**、**Notice 看板**（待办与伏笔清单，
勾掉就不再来烦你）、**发展线**（剧情节点按顺序推进，标出故事现在走到哪、下一步是什么）。

> 什么时候用：写完一章发现「这个人物怎么又变性格了」「上次埋的伏笔忘了」——那就是世界书里的关系和 Notice 该补了。

**AI 改世界书会先让你确认**：它更新设定时，界面上会弹一张改动对照卡，你看过、点了才归档。手滑改错不会被静默写进去。

### 章节与对话：可以后悔

每章有自己的草稿，对话历史独立于章节，上下文互不串（默认「绑定章节」：一章一段对话、切章节即切对话；设置里可以改成「分离」：对话与章节各聊各的，切章节不切对话）。右上角消息支持：

- **撤回**最新一轮，改了再发；
- 从**任意一条旧消息分叉**出新走向（比如「从上上轮重新来，但这次让她拒绝」），分支栏里可以来回切换。

> 什么时候用：AI 写歪了、想试试两种走向、或者你想保留这个版本但另一条路也想看看。

### 舞台：让角色当场演（实验功能）

导演控节奏、演员按各自角色即兴共演、编剧收幕成文。适合「我想看看这两个人碰面会怎么样」——
你给个场景，它们自己演，你在旁边喊停、改方向。剧本要经你确认才开演。

> 什么时候用：卡文、想给人物找感觉、想快速试一段对话。不想玩这套就开经典模式，编辑页变成一个直接干活的写作 agent。

### 上下文与压缩：长对话不崩

界面会显示上下文占用，超过 80% 会提示你；压缩时可以手动触发，压缩过程在消息流里有提示。

> 什么时候用：聊了很久开始变迟钝、或者它开始忘事。不用自己算，看到提示就点。

### 无缝同步：你可以在别处改

你用别的编辑器改正文或设定文件，界面会自己跟上（大约一秒），不用刷新。反过来也一样。
两边几乎同时保存时会拦下冲突，不会默默覆盖。

### 导出：交稿

支持 **TXT / Markdown / EPUB / DOCX**，也能直接复制全文；整本书可以打包带走、在另一台机器导入。

> 什么时候用：给人看稿、投稿、换机器、备份。

### 工作区面板：AI 的中间产物看得见

它查的资料、推演过程、写废的场景备选都会放进这里，按类别列出、点开可读。
好处是你知道它在干什么，也方便你回头捡回被否掉的点子——不会像纯聊天那样，上下文一压缩就没了。

### 可选能力（默认关闭，按需开）

| 能力 | 说明 |
|---|---|
| **执行命令** | 放开本机 shell，让它调 pandoc、git 这类工具。**高风险**：命令以你的身份真跑，路径限制对它无效；所以每条命令与输出都会实时显示在对话里。不用就别开。 |
| **MCP 扩展** | 接外部工具服务器（stdio / http / sse）。想让它用某个外部服务时再配。 |
| **换模型 / 多家服务商** | 设置页可以接多家、也能加自定义供应商与模型；还能调随机性（采样参数）和思考深度。 |

### 外观

三套主题（深夜书房 / 纸上书房 / 羊皮灯下），也能自定义。手机上打开会自动换成单手可用的布局。

### 技能：可以直接点名要它用某套方法

除了直接说人话，也可以点名技能：**大纲**、**评析**、**修改**、**网文创作方法**（结构、人物、情绪、爽点、
钩子、去 AI 味、题材卡）。在输入框打 `/` 能看到技能命令。

> 什么时候用：「帮我按网文的路子搭个大纲」「这段太 AI 味了，按去 AI 味的方法改」——这类明确要方法的时候。

## 常见困惑速答

- **「它能看到我在正文区写的东西吗？」** 你保存之后就能，没保存的看不到。所以改完先按保存。
- **「为什么它一次只写一个场景？」** 这是刻意设计：一次一个场景质量更稳、你也更好拦。要一整章就说「一次写完这一章」，它仍会拆开写。
- **「会把我稿子改坏吗？」** 可以撤回、可以分叉，改设定要你确认，两边同时改会拦冲突。真担心就导出备份一份。
- **「要联网吗？」** 默认不联网。要联网得自己开「执行命令」，或者挂 MCP。
- **「数据在哪、会上传吗？」** 在本机，不上传。不要报具体路径。

## 一周上手法（用户问「我该怎么用起来」时给这个）

| 时间 | 做什么 |
|---|---|
| 第 1 天 | 花两分钟把风格定下来（人称、题材、基调、篇幅、一段文风样本）；在世界书里立 3–5 个人物和一句话世界观 |
| 第 2 天 | 让它写第一章，一次一个场景，不满意当场说 |
| 第 3 天 | 让它把第一章冷读一遍，你挑最在意的三条让它改 |
| 第 4 天 | 去舞台试一段共演，给人物找感觉 |
| 之后 | 日更；每章收尾让它把新人物、伏笔、进度记进世界书；卡文了翻发展线看下一步 |

## 禁区

- 不报文件路径、不报内部字段名与工具名（见 SKILL.md 的翻译表）。
- 不承诺没有的能力：默认没有联网、没有 shell、没有图片生成。
- 不一次讲完。用户没问的，先不说。
